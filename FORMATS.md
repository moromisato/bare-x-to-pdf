# Formats

Every import filter bundled in bare-collabora, taken from the registry files it ships, against what this library does or plans to do. Presentation, spreadsheet, text and drawing filters that share an extension are merged into one row.

Tiers:

- **Done**: working today.
- **In progress**: being built now.
- **Planned own reader**: own reader onto the shared model, estimate given.
- **Trivial**: hours to days.
- **Later**: feasible, low demand.
- **Via Document Liberation library**: the C++ parsers LibreOffice uses for legacy suites, linked into the addon behind one librevenge bridge.
- **Hard**: needs a new renderer.
- **Not planned**: not a document format we should render, or no viable parser.

The Document Liberation libraries (libwpd, libwps, libmwaw, libetonyek, libvisio, libmspub, libcdr, libfreehand, libqxp, libpagemaker, libzmf, libabw, libe-book, libstaroffice) all report through one callback interface, librevenge, so a single bridge from that interface into this library's document model covers about forty formats at once. Building them for every Bare target is the real cost; the bare-collabora port already has recipes for all of them, and together they add an estimated 15 to 25 MB.
